# scoop-bucket

Personal Scoop bucket for Windows packages, including [`hermes-icon`](https://github.com/bulyaki/hermes-icon).

## Installation

```powershell
scoop bucket add bulyaki https://github.com/bulyaki/scoop-bucket
scoop install hermes-icon
```

## Verify & Configure

```powershell
hermes-icon --version
hermes-icon pick
hermes-icon watch install
```
